Who this is

课猫 Echo is an English and Chinese speaking-practice app made by Dibya Jyoti Sarangi (Play Console developer name Physicist_who_develops). This policy covers the Android app com.ayk.echo and the same app on the web at dsarangi7.github.io/Echo and echo-psi-ashen.vercel.app. Contact: dsarangi7@gmail.com. Developer site: dibya-portfolio-jet.vercel.app.

What the app does not do

There is no account, sign-in, or profile. The app does not show ads, and it does not include an analytics, advertising, or crash-reporting SDK. It does not ask for your name, email, phone number, contacts, photos, or location. It does not sell data. Practice audio is not uploaded.

Data that stays on this device

Progress is stored in the browser or WebView on the device, not on a server run by the developer. Clearing the site data, or uninstalling the Android app, deletes it. The keys are:

  • echo-practice-lang — English or 中文.
  • echo-practice-index — which sentence card was open.
  • echo-hear-pace — Hear it speed, per language.
  • echo-practice-streak — current streak, best streak, and the Shanghai calendar days that counted.
  • echo-practice-reminder — whether the reminder is on, and the clock time you picked (HH:MM on the device).
  • echo-office-words — Office words review progress.
  • echo-color-theme, echo-landing-dismissed, echo-app-mode, echo-match-tip, echo-whisper-interstitial — appearance and one-time notices.
  • echo-reminder-test-fired — whether the one-minute test notification already ran.
  • echo-session-tally in session storage — Clear / Partial / mic-unsure counts for the open visit. It is dropped when the tab or process closes.
  • IndexedDB database echo-practice-sync — a local copy of the streak and reminder so the website service worker can show a reminder. The Android app does not ship that service worker.
  • Cache API transformers-cache — the on-device speech model after it has been loaded. On the website the model is downloaded from this site (about 44 MB) on first use. The Android app includes those files in the package.

Older builds used echo-practice-days and echo-reminder-prefs. If those are still present and the new keys are empty, the app copies them once and deletes the old keys.

The Android app sets android:allowBackup="true". If you have Android backup turned on, Google may copy the app’s local data, including WebView storage, to your own Google account. The developer does not receive that backup and cannot read it.

Microphone

Say it, and Speak on the Translate screen, use the microphone only after you tap the button. The recording is turned into text on this device with Whisper tiny (the weights ship with the app; remote model hosts are disabled). The samples stay in memory for that transcription. The app does not save them as an audio file and does not send them to the developer or to a speech API. Hear it plays included recordings or the device voice. It does not use the microphone.

Translate

Translate is optional. Practice and word decks do not call it. When you translate, the page sends one HTTPS request from this device to MyMemory, operated by Translated: https://api.mymemory.translated.net/get. The request contains the sentence (at most 500 characters) and a language pair (en|zh-CN or zh-CN|en). Cookies are not sent (credentials: "omit"). No MyMemory account is used.

The code can also send a developer contact email as MyMemory’s de parameter when the site is built with VITE_MYMEMORY_CONTACT. That value would be the developer’s address, not yours. The public website bundle and the Android build instructions do not set it, so current builds do not send it.

MyMemory receives the sentence and, like any HTTPS server, the IP address of the connection. Their terms say they collect segments submitted to the service and store them long term, and that they may log IP address and visit data. This app does not get a copy of that log and cannot delete it. Their terms: mymemory.translated.net/terms-and-conditions. The developer does not use the sentence for advertising or to identify you.

A spoken Translate line is transcribed on this device first. Only the resulting text is sent. The audio is not.

Notifications

The daily reminder and the Monday streak summary are scheduled on the device. Nothing is sent to a push service. The notification shows a fixed title (课猫 Echo) and a sentence that can include how many Shanghai days you practiced. You choose the clock time. Leaving the switch off schedules nothing. The website may also show a local notification through the browser’s service worker. That still does not contact a developer server.

进度存在这台设备的浏览器或 WebView 里，不在开发者的服务器上。清除网站数据，或卸载 Android 应用，就会删掉。键名如下：

  • echo-practice-lang — 英语或中文。
  • echo-practice-index — 当前句子卡片。
  • echo-hear-pace — 每种语言的「听一听」语速。
  • echo-practice-streak — 当前连续天数、最佳天数，以及按上海日历记下的练习日。
  • echo-practice-reminder — 提醒是否打开，以及你选的设备本地时间（HH:MM）。
  • echo-office-words — 办公词汇的复习进度。
  • echo-color-theme、echo-landing-dismissed、echo-app-mode、echo-match-tip、echo-whisper-interstitial — 外观和一次性提示。
  • echo-reminder-test-fired — 一分钟后的测试通知是否已经响过。
  • 会话存储 echo-session-tally — 这一次打开期间的听清、部分、识别不准次数。关闭页面或进程后消失。
  • IndexedDB 数据库 echo-practice-sync — 连续天数和提醒的本地副本，供网站的 Service Worker 显示提醒。Android 安装包不包含这个 Service Worker。
  • Cache API transformers-cache — 加载后的本地语音模型。网站第一次使用时从本站下载（约 44 MB）。Android 应用把这些文件打进安装包。

更早的版本用过 echo-practice-days 和 echo-reminder-prefs。如果旧键还在、新键仍是空的，应用会复制一次并删除旧键。

Android 应用设置了 android:allowBackup="true"。如果你打开了 Android 备份， Google 可能把应用的本地数据（包括 WebView 存储）备份到你自己的 Google 账号。 开发者收不到这份备份，也不能读取。

麦克风

「说一说」，以及翻译页的「说一句」，只在你点下按钮之后使用麦克风。 录音在这台设备上用 Whisper tiny 转成文字（模型随应用提供，不允许从远程模型站下载）。 采样只在这次识别的内存里。应用不会把它存成音频文件，也不会发给开发者或语音识别接口。 「听一听」播放自带录音或设备语音，不用麦克风。

翻译

翻译是可选的。练习和单词卡不会调用它。翻译时，页面从这台设备向 MyMemory（Translated 运营）发出一条 HTTPS 请求： https://api.mymemory.translated.net/get。请求里是这一句（最多 500 字）和语言方向 （en|zh-CN 或 zh-CN|en）。不发送 Cookie（credentials: "omit"）。不使用 MyMemory 账号。

如果构建时设置了 VITE_MYMEMORY_CONTACT，代码还会把开发者的联系邮箱放进 MyMemory 的 de 参数。 那是开发者的邮箱，不是你的。当前公开网站包和 Android 构建步骤都没有设置它，所以现有构建不会发送。

MyMemory 会收到这一句，并且和任何 HTTPS 服务器一样能看到连接的 IP 地址。 他们的条款写明：提交到该服务的句段会被收集并长期保存，他们也可能记录 IP 和访问数据。 本应用拿不到那份日志，也不能删除。条款： mymemory.translated.net/terms-and-conditions。 开发者不用这句话做广告，也不用它识别你是谁。

用语音翻译时，先在本机转成文字，发出去的只是文字，不是录音。

通知

每日提醒和周一的连续天数小结都排在这台设备上，不经过推送服务器。通知标题是固定的「课猫 Echo」， 正文里可以带上你在上海日历中练习了多少天。时间由你选定。开关关掉就不会安排。 网站也可能通过浏览器的 Service Worker 显示一条本地通知，同样不会联系开发者的服务器。
